Digital Millennium Copyright Act (DMCA) Notice

Notice to Copyright Holders: CineBox is a client-side search indexing software client. CineBox does not host, upload, store, or stream any digital video files. All media endpoints are hosted on independent third-party servers.

1. How CineBox Operates

CineBox is an open-source software project that provides an interactive user interface for querying publicly available metadata and links across the open web. It operates in the same conceptual classification as general web browsers (such as Firefox or Brave) and media players (such as VLC).

2. Source of Media Content

None of the media files, video streams, or content presented in CineBox reside on servers operated or controlled by the CineBox developers.

The application does not possess upload capabilities, file storage infrastructure, media databases, or content streaming servers. It indexes hyperlinks created and maintained by third parties.

3. Proper Procedure for Takedown Requests

Because CineBox has no physical custody or technical control over the third-party hosts where media files are stored, sending a takedown request to CineBox cannot remove the file from the internet.

To effectively protect your copyright and remove infringing material from the web, please send your DMCA takedown notice directly to the web host, cloud storage provider, or CDN hosting the media file itself.

4. Removing Broken or Inaccurate Metadata Indexers

If you are a copyright owner and identify an issue with scraper parsing logic within this open-source repository, you may submit an issue ticket or pull request on our public repository at:
