Non-Hosting & Copyright Disclaimer

1. Non-Hosting Statement

CineBox does not host, upload, store, stream, broadcast, or transmit any video files, media content, or copyrighted digital works on any central server or network infrastructure.

CineBox is an open-source software client engineered strictly as a client-side search crawler and metadata indexing interface. The application operates in a manner analogous to a specialized web browser or search engine: it crawls publicly accessible third-party web addresses and formats publicly visible metadata into a television- and mobile-friendly interface.

2. Third-Party Links & Playback

All video stream endpoints, file manifests, and media resources indexed or resolved by CineBox are hosted on external, unaffiliated third-party servers and content delivery networks. CineBox has no affiliation with, ownership of, or operational control over any third-party hosts or the digital media they store.

Playback functionality within CineBox is delegated directly to independent third-party media players (such as VideoLAN VLC) through operating system intents. Any data transfer occurs directly between the end user's device and the third-party server hosting the file.

3. DMCA & Copyright Compliance

CineBox respects intellectual property rights and adheres to the principles of the Digital Millennium Copyright Act (DMCA) and international copyright standards.

Because CineBox hosts no media files and has no capability to delete or modify content hosted on external third-party servers, copyright infringement claims and takedown notices must be directed to the third-party web service, hosting provider, or domain registrar that actually stores the file in question. Removing an index or link from CineBox would not remove the file from the internet, as the file remains on the external third-party host.
